# express-spring-bookube

A **fullstack book management app** built for practice, showcasing **Spring Boot + Hibernate for backend**, **Express + Prisma for auth**, **Next.js + React + TypeScript for frontend**, and **PostgreSQL** as the database. Optional Docker and Kubernetes setup included for deployment practice.

---

## Features

- User authentication (register/login) via **Express + JWT**
- Book CRUD (Create, Read, Update, Delete) via **Spring Boot + Hibernate**
- Frontend dashboard with **Next.js + React + TypeScript**
- API integration using **TanStack Query** for data fetching and caching
- PostgreSQL database with relational schema for users and books
- Optional: Dockerized services and Kubernetes manifests

---

## Tech Stack

| Layer             | Tech / Library                  |
|------------------|--------------------------------|
| Frontend          | Next.js, React, TypeScript      |
| State Management  | TanStack Query                  |
| Auth Service      | Node.js, Express, TypeScript, Prisma |
| Book Service      | Spring Boot, Hibernate ORM     |
| Database          | PostgreSQL                     |
| DevOps (Optional) | Docker, Docker Compose, Kubernetes |
